## Project
TeaShelf

## Goal
A tea inventory and tasting journal for tea enthusiasts.

## Target user
A single user who wants to track teas, tasting sessions, notes, and ratings.

## Core features
- Add and edit teas
- Record tasting sessions
- Save notes and ratings
- Search and filter teas
- View simple stats

## Non-goals
- No social network
- No scraping in v1
- No recommendations engine
- No marketplace/community features

## Constraints
- Python + FastAPI
- PostgreSQL
- Docker Compose
- Backend-first
- Keep v1 small and testable locally

## Deliverables
- Running API
- Database models and migrations
- Tests for core behavior
- Dockerized local setup
- Clear README

## Done when
- I can create a tea
- I can log a tasting session
- I can fetch and filter my teas
- Tests pass
- App runs with Docker Compose
